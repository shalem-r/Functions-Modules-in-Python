# Functions-Modules-in-Python

## Task 1: Factorial Using a Function

This program:
- Defines a function called `factorial`
- Uses a loop or recursion to calculate the factorial of a number
- Prints the result

📌 Example:
Enter a number: 6
Factorial of 5 is 720

## Task 2: Math Module Calculations

This program:
- Asks the user to enter a number
- Uses Python's `math` module to calculate:
  - Square root
  - Natural log (log base e)
  - Sine (in radians)
- Shows all results

📌 Example:
Enter a number 36
Square Root : 6.0
Logarithm : 3.58351893845611
Sine : -0.9917788534431158
